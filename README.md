# World Trade Center Lego

I built the world trade center in fusion 360 by modeling each lego brick in the set and then assembling it.

I looked through rebrickable until i found the set i wanted and i went with wtc because 9/11 was just a few days ago.
[Link to Rebrickable Set](https://rebrickable.com/mocs/MOC-159264/legorapcreations/lego-world-trade-center/#details)

Then i took the part number and put it in [bricklink.com](https://www.bricklink.com) for the dimensions.
Lastly once all bricks are made its as simple as building a normal Lego set
